# Staff coverage

In the staff area, open **Coverage**. Moderators can save weekly hours, dated availability and breaks. The planner prepares suggestions for planned lives automatically. Operations can add or cancel planned demand.

- **Proposed ◇**: a suggestion. Review dates, time zone, hours and stream count, then accept or decline.
- **Reserved ▣**: an accepted future commitment. It does not mean someone is present.
- **On shift ●**: the moderator explicitly selected Start and the current shift is valid.
- **Gap ⚠**: demand still needs eligible staff. Replacements always need their own acceptance.

Start is available from the scheduled start for fifteen minutes. A reservation never starts a shift automatically. Cancelling one commitment does not end a shift serving other sessions. Existing live approval and safety controls remain in charge.

Use **My hours** to enter availability. Dictation fills a draft only. Where approved assistance is available, a short instruction or plain-text schedule file can fill draft hours for review. Image/PDF reading is not supported. Manual input works when assistance is unavailable.

This release is an implementation with synthetic verification, not evidence of deployed or staffed coverage.
