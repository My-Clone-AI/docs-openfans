# Folha de gravação

Abra **Criador → Pessoas → Gravações**. Escreva notas sem dados privados e escolha **Preparar**, ou comece com **Nova folha**. Reveja o título, a data e as pessoas. Guarde as correções e escolha **Confirmar campos** uma vez. Continue com a verificação de direitos da gravação.

```text
Título: Estúdio
Gravado: 2026-10-01
Pessoa: Nome artístico | performer
```

Uma data sem hora fica incompleta. As datas previstas continuam previstas. Se várias pessoas usam o mesmo nome artístico, escolha a pessoa certa. Pode reabrir folhas durante sete dias; as retenções legais existentes continuam a aplicar-se.

A voz usa ditado no dispositivo quando disponível. Caso contrário, escreva ou use o ditado do teclado. A captura de fotos e documentos está indisponível. Nunca envie documentos de identidade, assinaturas ou dados pessoais privados.

Confirmar campos não verifica identidade, idade ou consentimento. As verificações das pessoas, autorizações e revisão humana mantêm-se.

# Shoot sheet (English)

Open **Creator → People → Recordings**. Add redacted shoot notes, then select **Prepare**. Review the title, completed capture date and people. Add missing fields, save corrections and select **Confirm fields** once. Continue with the recording's rights check.

Use one line per field:

```text
Title: Studio
Captured: 2026-10-01
Participant: Stage alias | performer
```

A date without a time stays incomplete. Planned dates stay planned. Choose the correct known person if an alias is shared. Sheets can be reopened for seven days. Remove a sheet to erase its notes.

Voice uses supported on-device dictation. If unavailable or denied, type or use the keyboard's dictation key. Photo and document capture are currently unavailable; use redacted notes. Never submit identity documents, signatures or private personal details.

Confirming fields does not verify anyone's identity, age or consent. Existing participant, release and human review checks still apply.
