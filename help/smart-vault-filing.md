# Organizar o cofre

Escolha **Organizar**, selecione uma pasta, os itens sem pasta ou o cofre e toque em **Preparar**.
Reveja nomes, etiquetas e pastas, guarde correções e escolha **Aplicar** uma vez. Os valores
existentes ficam protegidos até incluir cada campo. **Ignorar** mantém o item.

Na ficha de um item pode escrever uma nota e escolher **Aprovar nota**. Nomes de ficheiros e
notas importadas não contam como aprovação. Sem nota, o tipo e tamanho verificados permitem
sugestões técnicas. **Opções** guarda a escolha de nome e pasta. Pode escrever ou usar o
microfone quando o ditado no dispositivo estiver disponível. A voz nunca aplica alterações.

Volte a Organizar para continuar uma revisão guardada. **Desfazer** preserva alterações manuais
posteriores. Organizar não aprova nem publica conteúdo. A geração por IA e a leitura de fotos ou
documentos estão indisponíveis; a preparação técnica funciona. Funcionalidade pendente de
integração, sem publicação incluída.

## English

Choose **Organize**, pick unfiled items, a folder or the library, then **Prepare**. Keep browsing
while the batch prepares. Review the names, tags and folders, save any corrections, then **Apply**
once. Existing filing is kept unless you include that field. **Skip** leaves an item alone.

Add an optional filing note on an item's sheet and choose **Approve note** before preparing.
Old filenames and imported notes are not automatically approved. Without a note, verified type and
size can still suggest a folder. **Options** remembers a folder and naming choice. Keyboard input
always works; the microphone uses on-device dictation where supported and otherwise offers the
keyboard's dictation option. Voice never applies a batch.

Return to Organize to resume a saved review. Changed items are marked for a fresh review. **Undo**
restores matching organizer changes and preserves later manual edits. Filing does not approve,
publish or change access to media.

AI-generated filing and photo/document note capture are currently unavailable. Technical filing
continues to work. This feature is pending integration; no deployment is included in this change.

## Español

Elija **Organizar**, seleccione una carpeta, los elementos sin carpeta o la biblioteca y pulse
**Preparar**. Revise nombres, etiquetas y carpetas, guarde correcciones y pulse **Aplicar** una vez.
Los valores existentes se conservan hasta incluir cada campo. **Omitir** conserva el elemento.

Puede añadir una nota y **Aprobar nota** en la ficha del elemento. Los nombres de archivo y notas
importadas no son fuentes aprobadas. Sin nota, el tipo y tamaño verificados permiten sugerencias
técnicas. **Opciones** recuerda el nombre y la carpeta. Puede escribir o usar el micrófono cuando
el dictado local esté disponible. La voz nunca aplica cambios.

Vuelva a Organizar para continuar una revisión guardada. **Deshacer** conserva los cambios
manuales posteriores. Organizar no aprueba ni publica contenido. La generación por IA y lectura
de fotos o documentos no están disponibles; la preparación técnica funciona. Función pendiente
de integración; esta entrega no incluye publicación.
