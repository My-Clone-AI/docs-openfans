# Uploads

Pending review. Not released.

Select files to send them together. Uploads adjust to the connection and recover automatically
while this tab stays open. Pause, continue or cancel each file or the batch. After refreshing
or leaving the page, choose files again. Files stay private and still need checks and review.

The queue shows "Uploaded" only after the server confirms receipt. Open the existing item to
see its checks and next action. A file that cannot continue offers a short reason and the
available next action. No connection settings or chunk sizes to choose.

Implementation and verification: [proposed change #48](https://github.com/My-Clone-AI/openfans/pull/48),
`docs/features/adaptive-upload.md`.
